# 探索感

探索是玩家的主动行为

发现未知—>主动思考决策—>获得反馈—>更新认知 —>新的未知


空间——空间结构的可能性

规则——规则交互结果的可能性

叙事——故事发展的可能性



## 探索感和惊喜感

走在大路->不经意触碰石块->呀哈哈 是惊喜


走在大路->发现缺角的石阵->思考搬石头补缺->呀哈哈 是探索


共同点：未知与反馈

不同点：主动行为

## 核心链路

发现未知->主动思考决策->获得反馈->更新认知->新的认知

更新认知（满足好奇心）是探索的核心乐趣

## 玩家探索什么？

### 空间

（更新认知中）
隐含空间->观察并主动往对应方向探索->成功抵达对应空间->构建出新的空间关系

核心对象连通性

- 理解空间关系产生的尤里卡时刻

- 可通过高低差、单向门放大好奇心

### 规则

（更新认知中）
随机获得xxx(对可能的结果产生好奇)->主动搭配构筑->触发法杖效果获得物理反馈->更新认知、构想新的组合效果

- 规则探索需提供清晰的系统交互反馈链路

- 规则探索的核心聚焦于规则交互结果的可能性

### 叙事

（更新认知中）

对分支选择后的故事发展产生好奇—>主动选择不同分支—>获得不同分支的情节发展—>对后续可能发展产生遐想

- 故事发展三种层级：人物、事件、世界观

- 叙事探索的核心聚焦于故事发展的可能性。
